# 2-Bit SNN Multiplier 突觸權重連接表

此表格詳細列出了 2-bit SNN 乘法器各個子模組（AND 閘與半加器）內部的突觸連接、權重及延遲設定。

## 1. 1-bit AND 閘 (偏積生成)
| 源神經元 (From) | 目標神經元 (To) | 突觸屬性 | 權重 (Weight) | 延遲 (Delay) | 邏輯說明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `and_in[0]` | `and_out[0]` | 興奮性 (+) | 0.4 | 0 | 雙輸入(0.4+0.4=0.8) > 閾值(0.5) 時發火 |
| `and_in[1]` | `and_out[0]` | 興奮性 (+) | 0.4 | 0 | 單輸入(0.4) < 閾值(0.5) 則不發火 |

## 2. 半加器 (Half Adder) - 用於進位加法
下表適用於 `HA1 (pp1, pp2)` 與 `HA2 (pp3, c1)`。

| 路徑分類 | 源神經元 (From) | 目標神經元 (To) | 突觸屬性 | 權重 (Weight) | 延遲 (Delay) | 邏輯功能 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Sum 支路** | `ha_in[0]` | `ha_out[0]` | 興奮性 (+) | 1.0 | 2 | OR 基礎 (Sum 位) |
| **Sum 支路** | `ha_in[1]` | `ha_out[0]` | 興奮性 (+) | 1.0 | 2 | |
| **Carry 支路** | `ha_in[0]` | `ha_out[1]` | 興奮性 (+) | 0.4 | 2 | AND 基礎 (Carry 位) |
| **Carry 支路** | `ha_in[1]` | `ha_out[1]` | 興奮性 (+) | 0.4 | 2 | |
| **XOR 抑制層** | `ha_in[0]` | `ha_hid[0]` | 興奮性 (+) | 0.4 | 1 | 檢測是否為雙輸入 (AND) |

### 全系統邏輯連線 (System Data Flow)
1. **輸入**: $A(A_1A_0)$ 與 $B(B_1B_0)$
2. **偏積層**:
   - $pp_0 = AND(A_0, B_0)$
   - $pp_1 = AND(A_1, B_0)$
   - $pp_2 = AND(A_0, B_1)$
   - $pp_3 = AND(A_1, B_1)$
3. **加法層**:
   - $P_0 = pp_0$
   - $(P_1, C_1) = HalfAdder(pp_1, pp_2)$
   - $(P_2, P_3) = HalfAdder(pp_3, C_1)$
4. **輸出**: 4-bit 積 $P(P_3P_2P_1P_0)$
